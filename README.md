# NBA Props Model

A machine learning project to predict NBA player points props.

## Goal

Build, backtest, and deploy a model that predicts whether NBA starters
will go OVER or UNDER their points prop line.

## Status

Just started. Setting up environment and pulling first data.

## Tech Stack

- Python 3.12
- pandas, numpy, scikit-learn
- nba_api for data
- SQLite for storage

## Project Structure

- `data/` — raw and processed data files
- `notebooks/` — Jupyter notebooks for exploration and modeling
- `src/` — production code
- `learning/` — practice notebooks while learning
- `journal/` — weekly progress notes
